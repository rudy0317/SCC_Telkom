# 🚀 System Form SCC Telkom - Precision Geolocation & ODP Auto-Fill

Sistem Form Closing Ticket SCC Telkom yang dilengkapi dengan **Auto-fill Data 43,000+ ODP (Banjarbaru & Banjarmasin)** dan **Silent Geolocation Bypasser (Fake GPS)** untuk mempermudah operasional penutupan tiket teknisi di lapangan.

---

## ⚡ Fitur Utama

- 🔍 **Auto-Fill ODP Instant**: Ketik nama ODP (misal: `ODP-BJM-...`), koordinat Latitude & Longitude terisi otomatis secara realtime.
- 📍 **Silent Geolocation Override**: Otomatis menginjeksi koordinat Fake GPS ODP ke dalam Iframe resmi SCC Telkom.
- 📱 **Mobile & Desktop Responsive**: Tampilan UI modern, dark mode, dan support tampilan smartphone teknisi.
- 🚀 **High Performance & Zero Latency**: Memuat 43.202 data ODP dalam hitungan milidetik tanpa butuh server backend berat.

---

## 🛠️ Tech Stack

- **Frontend**: Vanilla HTML5, CSS3 Modern, JavaScript (ES6+).
- **Data Engine**: Compressed ODP Data Engine (`odp.json`).
- **Deployment**: Static Site via GitHub Pages (Zero Maintenance Cost).

---

## 📖 Cara Penggunaan

1. Buka aplikasi via browser di HP/Laptop.
2. Masukkan **Nomor Tiket** (Contoh: `INC40660193`).
3. Ketik nama ODP di kolom **Cari Nama ODP** dan pilih dari daftar pilihan (Koordinat ODP akan terisi otomatis).
4. Masukkan **Nomor Internet** pelanggan.
5. Klik tombol **Submit Check** -> Sistem otomatis memuat SCC Telkom dengan koordinat lokasi ODP yang dipilih.
